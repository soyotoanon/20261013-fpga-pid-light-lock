# AD9248 → FPGA → AD9767 光强 PI 固件

2026-10-15 修订；在 DSH 的 adc_pi_loop 工程上修改。板卡为 ATK-DF7A35，保留现有引脚和 UART 协议。当前实现为 PI，没有 D。

## 当前控制链路

模块原始 14 位补码 → 翻 MSB → 模拟前端极性修正 → 两路独立采样 → 选反馈通道 → 目标斜坡 → PI → 输出限幅 → DAC。

ADC 归一化采用现役 passthrough_5mhz_ob 相同公式 `y = ~(raw ^ 14'h2000)`，只做一次。内部 y/r 是 0..16383 的无符号码；误差为有符号差，范围 -16383..16383。归一化零点按该公式落在 8191/8192 附近，目标应以实际读回码标定，不能将数字中点等同于无光。

CH1 对应 ADC 时钟上升相位，CH2 对应下降相位，与现役直通固件的通道对应一致。默认反馈 CH1；寄存器 0x2D 可切 CH2。两路直通时 DAC1/2 各自跟随 ADC1/2；PI/固定码/信号发生器模式下两路 DAC 输出相同的选中码，当前不是两套独立闭环。

每个选中通道的新样本只产生一个 sys_clk 宽的 valid。PI、光丢失检测、统计只在该 valid 计算；不再由 CTRL_HALF 驱动。默认 ADC_HALF=4、sys_clk=50 MHz，对应每路 5 MS/s、PI 每 200 ns 更新一次。CTRL_HALF 只控制测试波形、扰动、日志和心跳。DAC使用分阶段写入：数据锁存后20ns发WRT，再20ns发CLK；固定码不重复写入。详见VALIDATION.md。

## 控制律和定点数

```
e[n] = r_active[n] - y[n]
u[n] = clip(u0 + s * (P[n] + trunc(Iq[n]/512)), OUT_MIN, OUT_MAX)
P[n] = trunc(e[n] / 2^KP_SHIFT)
dIq[n] = trunc(e[n] * 512 / 2^KI_SHIFT)
Iq[n+1] = clamp(Iq[n] + dIq[n], -I_CLAMP, +I_CLAMP)
```

`s=+1` 表示 DIR_POL=1，`s=-1` 表示 DIR_POL=0。积分项是带 9 位小数的有符号 32 位数。所有截断向零，正负误差对称。输出使用旧积分 I[n]，随后更新积分，符合本次给定的离散时序。

抗饱和先判断未限幅输出及积分对执行器的作用方向：处于上轨且积分继续推高输出，或处于下轨且积分继续压低输出时，停止该次积分；允许向内恢复。积分自身仍有硬限幅，缩小 I_CLAMP 后会收回新范围；33 位加法防回卷。输出和积分限幅在冻结/停用期间仍有效。OUT_MIN>OUT_MAX 时范围收缩为 OUT_MIN，主机正常配置接口会拒绝反向范围。

Kp=2^-KP_SHIFT，离散 Ki=2^-KI_SHIFT **每样本**。KP_SHIFT>=15 关闭 P，KI_SHIFT>=23 关闭 I；这是本次明确定义的关断值。增益仅支持二进制幂，不是任意实数系数。积分 Q9 的分辨率意味着 KI_SHIFT=12 时 |e|<8 码为积分死区；更小误差的积分需要减小 shift，或后续扩展小数位。改变 ADC 采样率会改变每秒积分强度，须重新换算 Ki；不要沿用原 50 kHz 控制时的数值直接判断稳定性。

## 在线目标与启停

SETPOINT、BIAS、Kp、Ki、方向、输出范围、积分范围均通过 UART 修改，无需重烧。SETPOINT 超出 14 位时饱和到 16383，不会截位回卷。SP_SLEW 默认为每个有效样本最多 1 码，0 按 1 处理。上限为 16383 码/样本；它是最大变化量，不代表物理功率单位。启用前 r_active 跟随反馈，启用后向请求值移动；正常 PI 运行时改目标不清积分，光丢失冻结时目标也停住。测试扰动先加入请求值再经过同一斜坡。

上电 PI 停用且未解锁，输出数字中点；中点不是经光路标定的零功率。只有 LOOP_ARM 写 0xA501、CTRL[0]=1、PI 模式且不直通时才计算闭环。反馈方向/通道改动会取消解锁。每次重新进入 PI 自动清积分并装载限幅后的 u0，随后从反馈开始目标斜坡。切换到 PI 的输出可能跳到 u0，因此启用前先用固定码运行到同一个已标定 u0；这里没有宣称任意模式切换无扰动。

CTRL=0 停止 PI 并保持末次输出；主机 --disable 同时取消解锁。CTRL[4] 装载基准并清积分，CTRL[8] 清积分；这些是电平位，用后须写回 0。LIGHT_TH 在归一化 ADC 码域设置，连续 256 个有效样本低于它时锁存光丢失，冻结 PI；默认 5 MHz 时窗口为 51.2 µs。LIGHT_TH=0 关闭暗场判据。默认 16 是未标定占位值，须按暗场实测更改。

## 构建与使用

```powershell
python scripts/test.py
scripts\build.cmd
python -m pip install -r host/requirements.txt
python host/llctl.py --port COM5 --info
python host/llctl.py --port COM5 --feedback 1 --slew 1 --setpoint 8192
```

先完成固定码/直通数字检查，再做 AOM 开环标定。确认方向、u0、输出范围及增益后，才使用 `--arm --enable`。完整流程见 README_TESTS.md；寄存器表见 README_REGISTERS.md。此项目输出 bitstream/light_lock_top.bit，当前直通工程保持独立。

仿真和 Vivado 内部时序验收不代表真实光路稳定、实测闭环带宽或 IO 电气时序验收。现有 XDC 对 ADC/DAC 外部数据端口使用 false_path，仍沿用已验证低速接线方案；没有据此证明外部引脚时序。采样率不是闭环带宽。旧版本文档与五份依赖旧语义的测试保存在 docs/legacy_20261014 和 tb/legacy_20261014，不能用其中旧的“12 份全通过”作为本版证据。
