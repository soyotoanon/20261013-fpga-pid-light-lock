# 本版验证与数字链路操作

## 自动验证

`python scripts/test.py` 使用 Vivado 2023.2 的 xvlog/xelab/xsim；每一步检查退出码、仿真失败文本以及结束标记。日志保存在 build/revision_sim。

本版9份测试：7份既有独立模块回归（ADC统计、三份信号发生器/查表、扰动、扫描、UART）；新增 tb_pi_revision 数值与对象模型测试；新增 tb_sample_revision 全顶层 UART/采样/模式/保护测试。旧5份依赖原ADC码型、独立PI时钟或旧抗饱和行为的测试已归档，未作为本版通过证据。

新增PI测试以64位整数除法建立独立参考，检查正负满误差、增益关断、积分/输出限幅、冻结/启停、随机参数及两种符号的一阶对象收敛/目标变化恢复。新增顶层测试从真实UART引脚发送8字节帧并接收读应答，验证双通道归一化、单拍valid、5MHz每路更新、固定码和双路直通、目标饱和与斜坡、在线换反馈通道、解锁条件与光丢失冻结。数字对象模型不能代替真实AOM。

`scripts\build.cmd` 执行综合、布局布线、时序报告及bit生成。必须出现 FINAL_WNS、FINAL_WHS 非负和 BUILD_PASS；不存在有效时序路径也会失败。报告保存在 build；XDC的外部端口false_path限制见README。

## 上机数字检查（不需要先搭好AOM）

1. 烧录本版 bitstream/light_lock_top.bit，连接板载UART，安装 `python -m pip install -r host/requirements.txt`。COM5只是示例，替换实际串口。
2. `python host/llctl.py --port COM5 --info`，并读 `--read 0x2E` 确认0；读 `--read 0x2D` 确认默认CH1。
3. 固定输出：先 `--write 0x02 8192`，再 `--write 0x00 8`。示波器测两路DAC，改变0x02验证固定码链路。实际与DDS连接时使用已确认的控制电压范围。
4. 双路直通：`--write 0x00 2`，改变PD输入，核对两路各自响应。`--feedback 2` 只切PI反馈/ADC读回来源，不交换直通的两个DAC输出；用 `--feedback 1` 恢复。
5. 数字PI实验先保持执行器与真实光路闭环断开，`--write 0x21 0` 关闭未标定的暗场判据。设置输出上下限、u0以及小增益；可用 `--pi 6 63` 先关闭积分，仅观察P的符号。0x20设方向后再次解锁。
6. `--setpoint 8192 --slew 1`，再 `--arm --enable`；确认改变目标时输出方向与误差一致。目标值应以读回的PD码为依据，8192仅示例。分别读0x03、0x04、0x05观察反馈/误差/输出。
7. 缩窄0x1E/0x1F至测试范围，构造持续误差，验证输出不回卷；恢复相反误差，验证能离开饱和。多寄存器设置前先 `--disable`；调好再解锁启用。
8. 结束数字测试用 `--disable`；这会保持末次PI输出，不等同于零光。需要某个确定输出时，切固定码并写入已确认的值。

## AOM搭好后的闭环阶段

先测 DAC码→RF幅度→衍射光强/PD码，确定局部斜率符号、可用上下限和u0，再确定目标码及光丢失阈值。固定码先运行到u0，然后从P-only开始，小幅加入I。每次改变ADC_HALF都重新换算每样本Ki。最后测真实延迟、噪声、稳定精度与闭环带宽；本次未执行硬件烧录、真实UART联机或AOM闭环实验。
